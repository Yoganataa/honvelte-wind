# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch. Older revisions are not guaranteed to receive backported fixes.

## Reporting a vulnerability

Do not publish vulnerability details, exploit code, credentials, or sensitive logs in public issues or discussions.

Use GitHub's **Security → Advisories → Report a vulnerability** flow when private vulnerability reporting is available for this repository. If that option is unavailable, contact the maintainer privately through the contact method listed on the [maintainer's GitHub profile](https://github.com/Yoganataa).

Include the affected revision, impacted component, potential impact, reproduction steps, and any known mitigations. Redact tokens, passwords, personal data, and unrelated user data.

Please allow the maintainer reasonable time to assess and address a report before public disclosure.
